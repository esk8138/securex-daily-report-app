# SecureX 일일 업무보고서 자동 생성 앱

SecureX 기술지원팀의 메신저 대화 내용과 JIRA 업무 CSV 데이터를 입력해 일일 업무보고서 초안을 만드는 실습용 웹앱입니다.

## 파일 구성

- `index.html`: 웹앱의 기본 화면 구조를 정의합니다.
- `style.css`: 보안회사 업무용 도구 느낌의 다크 모드 화면 스타일을 정의합니다.
- `app.js`: 작성일 기본값 설정, 샘플 데이터 불러오기, API Key 저장/삭제, 요약표 생성, 로컬 샘플 보고서 생성, OpenAI API 기반 AI 보고서 생성, 복사, TXT 다운로드, 초기화 동작을 처리합니다.
- `messenger_chat_sample.txt`: 메신저 대화 샘플 데이터입니다. 실습 참고 파일이므로 삭제하거나 이름을 바꾸지 않습니다.
- `jira_task_sample.csv`: JIRA 업무 샘플 데이터입니다. 실습 참고 파일이므로 삭제하거나 이름을 바꾸지 않습니다.

## 실행 방법

`index.html` 파일을 브라우저로 직접 열어도 기본 화면과 보고서 생성 기능을 사용할 수 있습니다.

화면은 좌우 2단 구성입니다. 왼쪽에는 작성일, API Key, 샘플 데이터, 메신저/JIRA 입력 영역이 있고, 오른쪽에는 업무 현황 요약표와 일일 업무보고서 본문이 표시됩니다.

단, 브라우저 보안 정책 때문에 `file://` 주소에서는 `messenger_chat_sample.txt`, `jira_task_sample.csv` 파일을 직접 읽지 못할 수 있습니다. 이 경우 앱은 `app.js` 안에 들어 있는 동일한 샘플 문자열을 자동으로 불러옵니다.

샘플 파일을 실제 파일에서 읽는 흐름까지 확인하려면 로컬 서버에서 실행하는 방식이 가장 안정적입니다.

1. 이 폴더에서 터미널을 엽니다.
2. 아래 명령으로 간단한 로컬 서버를 실행합니다.

```bash
python -m http.server 8080
```

3. 브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:8080
```

4. `샘플 데이터 불러오기` 버튼을 누른 뒤 `로컬 샘플 보고서 생성` 버튼을 누르면 API Key 없이 업무 현황 요약표와 임시 업무보고서 본문이 출력됩니다.

## API Key 설정 테스트

1. `OpenAI API Key` 입력창에 테스트용 문자열을 입력합니다.
2. `API Key 저장` 버튼을 누릅니다.
3. 저장 상태가 `API Key 설정됨`으로 바뀌는지 확인합니다.
4. `API Key 삭제` 버튼을 누릅니다.
5. 저장 상태가 `API Key 미설정`으로 바뀌는지 확인합니다.

LocalStorage는 실습용 임시 저장소입니다. 실제 운영 서비스에서는 API Key를 서버에서 관리해야 합니다.

## 로컬 샘플 보고서 테스트

1. 브라우저에서 앱을 엽니다.
2. `샘플 데이터 불러오기` 버튼을 누릅니다.
3. `로컬 샘플 보고서 생성` 버튼을 누릅니다.
4. 보고서 출력 영역 상단에 `보고서 생성 방식: 로컬 샘플 생성` 문구가 표시되는지 확인합니다.
5. `[일일 업무 요약]`, `[주요 완료 업무]`, `[진행 중 업무]`, `[지연/이슈 사항]`, `[내일 예정 업무]`, `[지원 필요 사항]`, `[내부 공유 메모]` 섹션이 출력되는지 확인합니다.
6. 업무 현황 요약표에 `구분`, `주요 내용`, `담당자`, `상태`, `우선순위`, `다음 조치` 컬럼이 표시되는지 확인합니다.
7. 우선순위가 `High`인 행이 강조 표시되는지 확인합니다.
8. 화면 하단에 `보고서 생성 시각`이 표시되는지 확인합니다.

## AI 보고서 생성 모드 테스트

1. API Key를 저장하지 않은 상태에서 `AI 보고서 생성` 버튼을 누릅니다.
2. `API Key가 설정되지 않았습니다. 먼저 API Key를 입력해 주세요.` 메시지가 표시되는지 확인합니다.
3. 유효한 OpenAI API Key를 저장합니다.
4. `샘플 데이터 불러오기` 버튼을 눌러 메신저 대화와 JIRA 업무 데이터를 입력합니다.
5. `AI 보고서 생성` 버튼을 누릅니다.
6. `AI 보고서를 생성 중입니다...` 메시지가 표시된 뒤, `[일일 업무 요약]`부터 `[내부 공유 메모]`까지의 AI 보고서 초안이 출력되는지 확인합니다.

API 호출 오류가 발생하면 아래 기준으로 한국어 메시지가 표시됩니다.

- 401: `API Key가 유효하지 않습니다.`
- 429: `API 호출 한도를 초과했습니다. 잠시 후 다시 시도해 주세요.`
- 500번대: `OpenAI 서버 오류입니다. 잠시 후 다시 시도해 주세요.`
- 기타 오류: `보고서 생성 중 문제가 발생했습니다. 입력값과 API Key를 확인해 주세요.`

## 복사와 다운로드 테스트

1. 로컬 샘플 보고서 또는 AI 보고서를 생성합니다.
2. `보고서 복사` 버튼을 누른 뒤 텍스트 편집기에 붙여 넣습니다.
3. 업무 현황 요약표와 일일 업무보고서 본문이 함께 포함되어 있는지 확인합니다.
4. `TXT로 다운로드` 버튼을 누릅니다.
5. `securex_daily_report_YYYY-MM-DD.txt` 형식의 파일명으로 다운로드되는지 확인합니다.
6. TXT 파일 안에 요약표가 텍스트 표 형태로 포함되어 있는지 확인합니다.

## 초기화 테스트

1. 보고서를 생성한 뒤 `초기화` 버튼을 누릅니다.
2. 메신저 대화 입력 영역과 JIRA 업무 데이터 입력 영역이 비워지는지 확인합니다.
3. 업무 현황 요약표가 기본 안내 문구로 돌아가는지 확인합니다.
4. 일일 업무보고서 본문과 보고서 생성 시각이 초기 상태로 돌아가는지 확인합니다.
